# Ticket 235 notes: keyboard-only focus rings, script tilt on phones, Directions in a new tab

Items: M11a, M28 (focus), M26 (tilt), M31b (Directions).

## What changed

- `src/utils/focusRing.ts` (new, called from `src/index.ts`): tracks the last input. When focus lands after a tap or click, or on a `tabindex="-1"` target a script focused (step headings, modal containers, scrolled-to sections), it sets inline `outline: none` until focus leaves. Any key press (Tab included) restores the ring on a focused control, so keyboard users still see a ring on every control. Code-only: no CSS is needed in the site head, so nothing to paste in release ticket #229 for this.
- `src/utils/scriptTiltSpace.ts`: the module already reads the computed `rotate` at the current width, so phones were never skipped in code; the gap was the History "George Marston" heading missing from the selector and from the phone CSS. Selector now includes it. `docs/reference/site-head/script-tilt.css`: the George Marston rule (-2.56deg) now sits outside the 768px media query so it tilts on phones too. Companion ticket #229 must paste the updated `script-tilt.css` into the site head embed.
- `src/utils/directionsLinks.ts` (new, called from `src/index.ts`): every `a[data-map-directions]`, `a[href*="destination="]` and Google Maps `dir` link gets `target="_blank"` and `rel="noopener"`. `src/utils/map.ts` also applies it when it rewrites the CMS row link. `mapNeeds.ts` builds no links.
