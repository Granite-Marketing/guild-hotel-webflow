## M20. Hero text always visible on mobile (svh)

- **Where:** full-screen hero sections on mobile, e.g. Garden Terrace (Loom 9:16), where the title sits under the browser's bottom bar; every full-height hero.
- **Cause (likely):** heroes use `100vh`. On mobile browsers `vh` is the tallest viewport (toolbars hidden), so content anchored to the bottom falls behind the browser bar when the page loads.
- **Decision (Stephen):** use `svh` (small viewport height) for hero heights on mobile so the title, text and buttons always show. Desktop stays on `vh`.
- **Conflict to record:** this reverses the standing "vh, never svh" rule for mobile heroes. Update that rule in the repo's CLAUDE.md when this ships (mobile hero heights are the exception), and check the hexagon scroll masks still open to full screen (F55).
- **Screenshot:** `m20-loom-hero-text-cut-off.webp`.
