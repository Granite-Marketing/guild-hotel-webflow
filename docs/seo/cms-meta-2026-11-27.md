# CMS meta titles and descriptions (27 Nov 2026)

Stephen, 27 Nov: "We are missing the SEO fields for the rooms, blogs and CMS collection pages that will be actual pages. We need SEO - Meta Title (75 chars max), SEO - Meta Description (150 chars max)." Fields sit "at the top of the collection next to settings" and are linked in each template's SEO settings.

## What was done

- Two plain text fields, `SEO - Meta Title` and `SEO - Meta Description`, on the six collections whose template pages are published, in an **SEO** field group right after Settings (first group where there is no Settings group).
- Each template page's Title tag and Meta description read these fields; the Open Graph title and description copy them.
- Every value is within the limit (titles 75, descriptions 150). The Data API cannot set a field's character limit, so the limit is in the help text; set "Max length" in each field's settings to enforce it for editors.
- Checked on staging after publish: all 29 published item pages show the field values in the title tag, meta description and og:title. Wellness Experiences item pages return 404 (sub-pages on hold), so their values are filled but not live.
