Draft snippets for review. Nothing has been added in Webflow.

## What exists today

- **Repo: none in code.** `src/` has no structured data module. The home page also carries two hand-written Hotel blocks that contradict each other (rating 4.2 from 662 reviews vs 4.3 from 692; price range `$$$` vs `$150 - $350`; one claims free continental breakfast). ## 2. Static pages: BreadcrumbList

**Where:** each page's Page settings > Custom code > Inside `<head>` (or the page's Schema markup field). Home gets none.

Pattern (Dining shown):

```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "Home", "item": "https://theguildhotel.com/" },
    { "@type": "ListItem", "position": 2, "name": "Dining", "item": "https://theguildhotel.com/dining" }
  ]
}
```

Use the same block with these second-level values:

| Page | name | item |
|---|---|---|
| Rooms | Rooms | `/rooms` |
| Dining | Dining | `/dining` |
| Wellness | Wellness | `/wellness` |
| Meetings | Meetings & Events | `/meetings` |
| History | Our History | `/history` |
| Neighborhood | Neighborhood | `/neighborhood` |

## 3. CMS templates

**Where:** the template's Page settings > Custom code > Inside `<head>`. Values in `{{...}}` are Webflow field bindings: put the cursor there and use **+ Add field** to insert the named field. Field names are as shown in the Webflow CMS.

Binding rules to check in the Designer preview before publishing:

- A plain text value containing a double quote breaks the JSON. Current room, dining and story names have none.
- Date fields must print as ISO 8601 (for example `2026-11-14T09:30:00Z`). If Webflow prints a formatted date, pick the ISO format in the field's format option.
- Image bindings must print the image URL.

### Rooms template (`/rooms/<slug>`): HotelRoom + BreadcrumbList

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "HotelRoom",
      "@id": "https://theguildhotel.com/rooms/{{Slug}}#room",
      "name": "{{Name}}",
      "url": "https://theguildhotel.com/rooms/{{Slug}}",
      "description": "{{SEO - Description}}",
      "image": "{{Room - Image}}",
      "occupancy": { "@type": "QuantitativeValue", "maxValue": "{{Quiz - Max Guests}}", "unitText": "guests" },
      "containedInPlace": { "@id": "https://theguildhotel.com/#hotel" }
    },
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        { "@type": "ListItem", "position": 1, "name": "Home", "item": "https://theguildhotel.com/" },
        { "@type": "ListItem", "position": 2, "name": "Rooms", "item": "https://theguildhotel.com/rooms" },
        { "@type": "ListItem", "position": 3, "name": "{{Name}}", "item": "https://theguildhotel.com/rooms/{{Slug}}" }
      ]
    }
  ]
}
```

- `SEO - Description` is the new field proposed in the meta draft. Until it exists, bind `Hero - Intro`, which is currently the same sentence on every room.
- Bed type and floor size are left out: there is no bed field, and the size field is display text ("85 m² size"). The staging room facts also disagree with the agency copy (Two Bedroom Loft Suite: "85 m²" and "1 Queen Bed" on staging vs 1,809 sq ft and two bedrooms in the agency sheet; City Level Below Ground: 2 guests vs up to four), so `Quiz - Max Guests` must be checked per room before this goes live.
- Google shows no rich result for HotelRoom; it is here to tie each room to the hotel.

### Optional: Event for happenings (category = Happenings)

Webflow's conditional visibility only hides an element; the hidden code stays in the page, so two Embeds (one per category) would both be read by Google. The clean route is a small bundle module, like the existing listing pattern doc: on `/happenings-stories/*` pages whose category is Happenings, inject this block. That is a code change and is not part of this draft.

```json
{
  "@context": "https://schema.org",
  "@type": "Event",
  "name": "{{Name}}",
  "description": "{{Hero - Excerpt}}",
  "image": "{{Hero - Image}}",
  "startDate": "{{Settings - Date}}",
  "eventStatus": "https://schema.org/EventScheduled",
  "eventAttendanceMode": "https://schema.org/OfflineEventAttendanceMode",
  "location": { "@id": "https://theguildhotel.com/#hotel" },
  "organizer": { "@id": "https://theguildhotel.com/#organization" },
  "url": "https://theguildhotel.com/happenings-stories/{{Slug}}"
}
```

Gaps before this is worth doing: end time, whether every happening takes place at the hotel, and ticket price or booking link. Google's event result needs at least name, start date and location.
