## Room pages (CMS: Rooms)

The Rooms template currently builds every room's title as `{{Name}} | The Guild Hotel` and its description from the **Hero - Intro** field. That field holds the same sentence on all 10 rooms ("Our rooms and suites pair historic character with generous, modern comfort throughout."), so every room would launch with an identical description. The agency also asks for per-room values (Before Launch tab, point 3).

To use the values below, the Rooms collection needs two new plain text fields, **SEO - Title** and **SEO - Description**, bound in the Rooms template's SEO settings, then filled per room. Keep `{{Name}} | The Guild Hotel` only as a fallback.
