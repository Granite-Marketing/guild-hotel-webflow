# Final review, Lane B: Webflow settings (2026-11-25)

Read-only. Nothing in Webflow, the CMS or the code was changed. Names are proposals until Stephen approves them.

**How it was read.** All 55 components (definitions, variants, props, element trees), 24 pages and templates in full, all 21 collections with every field and all 205 items, all from the Webflow data tools on 25 Nov. Every component's instance count was matched against a search of every page, template, slot and component. Variant differences come from the published stylesheet (staging publish of 23 Nov 11:18): each variant's class was put on its component's own element tree and every computed style compared with Base at 1440, 800, 650 and 390, which covers Webflow's desktop, 991, 767 and 479 steps. 991 gets the same rules as 800. Where a variant came out empty, `get_variant_styles` was read as well.

**Headline.**

- 63 variants besides Base. 28 have no instance anywhere, 3 change nothing at any width, 2 are identical to each other. 17 page-named variants are in use and do something, most only on phones: keep, rename.
- The split broke three things that were keyed to old variant ids (R1 to R3). These are faults on the live staging site, not tidiness.
- 91% of the 2.4 MB stylesheet is variant selectors (V1), and it stops Base edits reaching those variants.
- The CMS is wired but mostly holds placeholder copy, and four lists that editors need are still hand-built.

Width key: all = every width; 991 / 767 / 479 = that width and below; 992+ = desktop only; n/a = not a visual difference.
