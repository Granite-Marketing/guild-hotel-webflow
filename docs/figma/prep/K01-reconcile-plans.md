## Steps

1. Collect `proposedShared` from every `docs/figma/build-plans/Q0xx/plan.json`. Group proposals that do the same job (same role, near-identical styles) under one generic name. Prefer a class that already exists in `docs/reference/style-inventory.md` (regenerated by Q001).
2. Write `docs/figma/build-plans/shared-classes.md`: one row per shared class with name, styles per breakpoint, and the plans that use it. Add the same list as `shared-classes.json`.
3. Rewrite each plan's `tree` and `proposedShared` to use the canonical names, and move settled entries into `reusedClasses`.
4. Replace any variable name that Q001 did not create with the live name from `style-inventory.md`.
5. Check D02 in `docs/figma/decisions.md`: components ruled the same block must share one class family. Merge their plans if two exist.
6. Re-render each changed preview and re-run the screenshot compare for it.

## Definition of done

- Every class in every plan's tree is in `style-inventory.md`, `shared-classes.json` or that plan's own family.
- No two shared classes have the same role and near-identical styles.
- Changed previews re-rendered and compared.
- PR against main, listing every rename in the description.
