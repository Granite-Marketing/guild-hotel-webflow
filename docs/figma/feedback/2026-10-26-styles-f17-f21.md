# 2026-10-26 feedback: chamfer and link-bar style fixes (F17, F21)

Record of the shared-class changes for feedback items F17 and F21 in
`docs/figma/feedback/2026-10-26.md`. Plan approved by Stephen on 2026-10-26. All
changes are Webflow Designer class style writes; no `src/` changes. The runtime
modules that touch these elements (`scrollEnlargeSnap`, `galleryFilter`, `mediaTabs`)
only toggle `is-active`, so they need no change.

## How it was measured

An in-page script on staging at 1440x900. For every element with a polygon clip-path
or a button-outline SVG background it took the text node's line box from a `Range` and
the glyph ink extents from canvas `measureText()`, then reported the gap between ink and
box on each side. `dv` = top gap minus bottom gap; positive means the text sits low.
Calibration: it reproduces the pre-F02 numbers exactly (16.4 top / 11.7 bottom at
symmetric 0.5625rem padding).

Pages: `/`, `/accessibility`, `/arts`, `/contact`, `/dining` and the four `/dining/*`
venues, `/gallery`, `/guidelines`, `/history`, `/legal-corporate/corporate`,
`/legal-corporate/legal`, `/meetings`, `/neighborhood`, `/press`, `/privacy-policy`,
`/rooms`, `/rooms-individual`, `/wellness`, `/happenings-stories/historical-tours`,
`/post-categories/blog-collection`, `/post-categories/happenings-collection`,
`/build-overlay-detail-panel-modal` (dialogs force-opened in the measuring tab only).

  book your space (`is-dark`), read our faqs, learn more (`is-burgundy`), reserve a

  symmetric `0.5625rem` top and bottom.

## F21: chevron link bars, links not centred or evenly spaced

Two class families draw this shape.

### `.tab-pills-intro_tabs` (Wellness media bar, gallery/arts sticky tags, press, neighborhood, post categories)

- **Vertical cause:** link boxes are centred (17.2px above and below), but the Sackers
  small-caps ink sits low: 25.6 / 20.5 (dv +5.1) on every page. The `is-active`
  underline adds weight below the text, which matches screenshot 11 (24 above, 20 below).
- **Horizontal cause:** gaps are even (44.5px) but the edge padding is 60px, so the
  links do not look evenly spread inside the shape. Figma's Wellness bar (284:3906) has
  edge padding 44 and gap 45. Other Figma bars are fixed-width shapes, so the consistent
  rule adopted is side padding equals column gap.
- **Changes:**
  - `.tab-pills-intro_tab`: padding-bottom 0.25rem; border-bottom 1px solid transparent.
  - `.tab-pills-intro_tab.is-active`: text-decoration none; border-bottom-color
    currentColor.
  - `.tab-pills-intro_tabs` side padding: base 3.75rem to 2.8125rem; medium 2.5rem to
    2rem; small 1.75rem to 1.5rem (top/bottom 0.875rem kept); tiny 1.5rem to 1.25rem.
    Height 3.5rem and the `is-scroll` / `is-media` combos unchanged.

### `.venue-card-fullbleed_tabs` (dining, meetings, legal-corporate media tabs)

- Already vertically centred (dv +0.1); its tab pattern is the reference used above.
- Edge padding 36px against a 44.5px gap. Change: base padding-left/right 2.25rem to
  2.8125rem (top/bottom 1.0625rem kept); medium adds 1.75rem left/right. Small and tiny
  are already equal.
