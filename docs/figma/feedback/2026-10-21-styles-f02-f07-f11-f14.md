# 2026-10-21 feedback: shared style fixes (F02, F07, F11, F14)

Record of the shared-class changes made for feedback items F02, F07, F11 and F14 in
`docs/figma/feedback/2026-10-21.md`. Plan approved by Stephen on 2026-10-21. All
changes are Webflow Designer style or component writes; no `src/` changes.

## F02: chamfered button text sits low

- **Cause:** `.button.is-chamfer` has `min-height: 2.3125rem` (37px) with symmetric
  0.5625rem padding. Sackers Gothic lowercase (small caps) ink sat about 2px below the
  vertical centre (16.4px above the ink, 11.7px below at 37px tall).
- **Change:** `.button.is-chamfer` padding-top `0.5625rem` to `0.375rem`, padding-bottom
  `0.5625rem` to `0.6875rem`. Height stays 37px; the ink is now centred to within 0.2px.
- **Scope:** every chamfer variant (solid, `is-outline`, `is-outline-light`, `is-dark`,
  `is-burgundy`, `is-blue`, `is-text-burgundy`, `is-wide`) and form submit inputs, plus the
  Reserve a Table button (F10). There is no chamfer small variant. No breakpoint overrides.

## F07: newsletter email label far above the line

- **Figma:** "*Email" sits on the underline, level with the "join us" button text
  (guidelines/08 spec: label y 503 to 519, button text 500 to 519).
- **Cause:** `.cta-booking-newsletter_label` was absolutely positioned 2.6875rem above the
  input bottom.
- **Change:**
  - `.cta-booking-newsletter_input`: padding-top `0` to `0.5rem`, padding-bottom `0.5rem`
    to `0.75rem`, so typed text lines up with the button text after F02. The
    `::placeholder` state gets `text-transform: none`.
  - `.cta-booking-newsletter_label` becomes an inline prefix on the line: `position:
    static`, flex none, height 2.3125rem, the same padding as the input, 1rem font (Figma
    size), and its own 1px bottom border. `margin-right: -1.25rem` with `padding-right:
    1.75rem` cancels the form's 1.25rem column gap so the underline is continuous; the
    tiny breakpoint uses -0.75rem and 1.25rem to match that breakpoint's 0.75rem gap.
- **Decision:** the approved plan used an input placeholder with a visually hidden label.
  The Webflow MCP cannot set an input placeholder (see
  `docs/solutions/integration-issues/webflow-mcp-input-placeholder-not-settable.md`), so
  the label was made an inline prefix instead. It stays visible while typing, keeps a real
  `<label for>`, and needs no manual Designer step. Swap to the placeholder approach later
  if Stephen prefers the label to disappear on typing.

## F11: forms narrower than the Figma column

- **Figma:** at 1600px the guidelines form column runs 690 to 1520 (830px wide).
- **Cause:** both form grids sit inside `container-large` (80rem cap), giving 723 to 1440
  (717px) at 1600.
- **Change (desktop only), on `.form-split-script-contact_component` and
  `.form-contact-fields_component`:**
  - `grid-template-columns: minmax(0, 0.735fr) minmax(0, 1fr)` (was 0.785fr)
  - `width: min(90rem, 100vw - 4rem)`
  - `margin-left: calc((100% - min(90rem, 100vw - 4rem)) / 2)`
  - Tablet (`medium`) resets `width: 100%` and `margin-left: 0rem`.
- **Result in local preview:** 1600: 690 to 1520 (matches Figma); 1440: 615 to 1408;
  1920: 850 to 1680. No horizontal scroll at those widths.
- **Pages:** Guidelines, Press, Legal, Corporate, Meetings (split-script family) and
  Contact (contact-fields family). Contact's Figma form sits 37px further left than
  Guidelines, so Contact is close to Figma rather than exact.

## F14: card title to list gap

- **Cause:** 42px = `.image-trio-text_item-content` row-gap 22px + the site-wide `ul`
  margin-top 16px + first `li` margin-top 4px. Webflow MCP cannot style tags nested in a
  rich text block, and the site-wide `ul` style affects every page.
- **Change:** new combo `.image-trio-text_item-content.is-list` with `row-gap: 0rem`,
  applied to the three card content wrappers in the Image Trio Text Left Offset component
  (`f6f42b26-759f-d2b6-03de-516393880a37`), which serves Legal and Corporate.
- **Result:** 20px on all three cards (52% cut). Figma's own gap is 22px.
